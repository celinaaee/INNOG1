# MyCV – Godkendelsesopgave 2

## Beskrivelse
MyCV er en mobil CV-app udviklet i React Native med Expo. Appen fungerer som et digitalt og interaktivt CV, hvor brugeren kan præsentere sin uddannelse, arbejdserfaring, projekter og kontaktoplysninger.

Appen er en videreudvikling af godkendelsesopgave 1 i faget Innovation og Ny Teknologi.

## Funktioner
- **Home:** Forside med personlig præsentation.
- **Experience:** Oversigt over uddannelse og erfaring.
- **Contact:** Kontaktoplysninger og mulighed for at sende e-mail.
- **Projects:** Ny skærm, hvor man kan søge efter, tilføje og slette projekter.
- **Datalagring:** Projekter gemmes lokalt med AsyncStorage, så de bevares, når appen lukkes.
- **Navigation:** Navigation mellem appens skærme.

## Teknologier
- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage

## Installation
1. Klon repository'et fra GitHub.
2. Åbn projektmappen `MyCV` i VS Code.
3. Kør `npm install` i terminalen.
4. Start appen med `npx expo start`.
5. Scan QR-koden med Expo Go på din telefon.

## Videreudvikling
I godkendelsesopgave 2 er appen blevet udvidet med en projektside, søgefunktion og lokal datalagring.

Derudover er koden blevet ryddet op ved at fjerne ubrugte imports og styles på baggrund af feedback fra godkendelsesopgave 1.
