# MyCV

MyCV er en mobil CV-præsentationsapp udviklet i React Native som en del af kurset Innovation og Ny Teknologi.

## Funktioner

Appen indeholder:
- Forside med navigation
- Side med erfaring
- Kontaktside
- Liste over erfaring
- Mulighed for at sende e-mail

## Teknologier

- React Native
- Expo
- React Navigation

## Start appen

Installer dependencies:

npm install

Start derefter appen:

npx expo start
